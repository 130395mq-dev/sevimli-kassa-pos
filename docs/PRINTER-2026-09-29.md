- Yangi kodning haqiqiy USB uzish/qayta ulash sinovi hali yakunlanmagan.
- Monitor faqat shu ishga tushirishdagi joblarni kuzatadi. Restartdan keyin
  eski Windows navbati avtomatik qayta yuborilmaydi; kassir navbat/qog'ozni

- Monitor universal fizik chop etish tasdig'i emas; uzilgan kabel, qog'oz

  ro'yxatini olish bu o'zgarish doirasida fon ishiga o'tkazilmadi.
